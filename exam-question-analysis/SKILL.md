# 考试题目解析与知识扩展 → PDF

用户每问一道考试/习题类题目，都按此流程产出"解析 + 逻辑链扩展 + 精美 PDF"。

## 第 1 步：解题（先给答案）

1. 直接给出**正确答案**，明确标注（如：正确答案：C）。
2. **逐项辨析**每个选项：
   - 正确选项：说明为什么对（对应哪条概念定义/关系）；
   - 错误选项：说明错在哪——归纳错误类型（张冠李戴 / 颠倒主次 / 唯心主义立场 / 概念混用 / 绝对化），并指出该选项实际对应的正确表述。
3. 若题干有引文/材料（如领导人讲话、案例），点出**引文与考点的对应关系**（如"问题导向→承认矛盾的普遍性、客观性"）。

## 第 2 步：知识扩展（前后逻辑链）

不孤立讲题，把考点放进所属知识体系的完整逻辑链中：

1. **定位**：该知识点在学科体系框架中的位置（如唯物辩证法：总特征 → 三大规律 → 五对范畴）。
2. **前世（逻辑起点）**：它由哪些更基础的概念推出；为什么必须讲它。
3. **本身**：核心内容，用**表格/对比**呈现（含义 / 特点 / 关系），突出易错点（如"无条件 vs 有条件"的归属）。
4. **纵深**：由该知识点衍生出的下一层概念（如普遍性→特殊性→不平衡性→内外因）。
5. **归宿（方法论）**：落到方法论/实际应用，说明"学它用来干什么"。
6. **回扣真题**：把原题作为案例完整解析（选项对照表：选项 / 说法 / 考点 / 错误原因）。
7. **记忆口诀 + 常见陷阱对照表**（陷阱说法 vs 正确表述）。
8. 若内容成体系，加一张**前后逻辑总览图**（用 .flow 盒子 + 箭头，HTML 里已定义样式）。

## 第 3 步：生成 PDF

1. 读取本 skill 目录下 `template.html`，在占位符处填入内容，**CSS 样式保持不变**。
2. 写入 `/tmp/<短名>.html`。
3. 用 headless Chrome 转换：

```bash
google-chrome --headless --disable-gpu --no-sandbox \
  --print-to-pdf="/home/crf/Documents/<文件名>.pdf" \
  --no-pdf-header-footer /tmp/<短名>.html
```

4. **验证**：
   - `pdfinfo "<pdf路径>" | grep Pages` 检查页数正常；
   - `pdftotext "<pdf路径>" -` 抽查各章节标题齐全、中文无乱码。
5. 删除临时 HTML：`rm /tmp/<短名>.html`。
6. 汇报：文件路径、页数、文档结构一览表。

## 命名与位置

- 一律保存到 **`/home/crf/Documents/`**；
- 文件名：`<专题名><知识点名>-解析扩展.pdf`，用完整中文名（如 `唯物辩证法矛盾观专题-知识点逻辑扩展.pdf`）。

## 排版规范（template.html 已内置，勿改动核心样式）

- 字体：`Noto Serif CJK SC` / `Noto Sans CJK SC`（系统已装，中文 PDF 依赖它，不要换成其他字体）；
- 标题：深红 `#8b1a1a` + 左侧 4px 竖条；
- 表格：全边框，表头浅红底 `#f0e6e0`；
- 引文 blockquote：米黄底 `#f7f3ee` + 金色左边条 `#c9a227`；
- 答案框：绿色圆角框，正确答案绿色加粗；
- 提示框 .tip：浅蓝底 + 蓝色左边条；
- 逻辑链 .flow：红边圆角盒子 + 箭头（用 inline-block，A4 宽度下自动换行）；
- 每个 h2 前 `page-break-after: avoid`，表格 `page-break-inside: avoid`。

## 注意事项

- **学科内容必须准确**：概念定义、条件归属（普遍性无条件/特殊性有条件、斗争性无条件/同一性有条件）、"谁决定什么"（性质→主要方面，地位→主要矛盾，本质→特殊性）等易错点不能写错。
- Chrome 转换必须带 `--no-pdf-header-footer`，否则 PDF 有浏览器页眉页脚。
- 若用户只问解题不要文档，或明确指定其他输出格式，遵循用户指示，跳过对应步骤。
